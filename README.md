# Sustainable Behaviours Study

This repository contains an exploratory data science study on self-reported sustainable behaviours using the 2021 AVQ microdata. The project focuses on two target variables:

- `SPRACQUA`: attention to water-saving behaviours
- `SPRENER`: attention to energy-saving behaviours

The objective is not to build a highly accurate predictive model. The goal is to understand whether other behaviours, attitudes, and socio-demographic variables are associated with stronger or weaker attention to water and energy saving. The repository therefore combines preprocessing, exploratory analysis, clustering, and random-forest-based feature screening.

Background materials, documentation, and questionnaire notes are stored in [about/](about/). Raw and processed data are stored in [data/](data/).

## Project Scope

The study asks a simple substantive question: do water-saving care and energy-saving care appear as isolated habits, or as part of a broader behavioural profile?

The current workflow treats machine learning as an exploratory instrument. Random Forest models are used mainly to rank variables by their association with the target variables, while the final interpretation relies on overlap across targets, descriptive plots, and behavioural consistency.

## Data

The analysis uses the 2021 AVQ survey microdata available in [data/AVQ_Microdati_2021.csv](data/AVQ_Microdati_2021.csv). The project builds derived target files and a cleaned feature matrix from that source:

- [data/preprocessed_data.csv](data/preprocessed_data.csv): cleaned feature matrix used in the downstream analyses
- [data/tar_spracqua.csv](data/tar_spracqua.csv): target for water-saving care
- [data/tar_sprener.csv](data/tar_sprener.csv): target for energy-saving care

Target coding is ordinal:

- `1` = high care / high attention
- `4` = low care / no attention

## Workflow

The project is organized as a linear pipeline.

1. [1_data_ingestion_first_dim_reduction.py](1_data_ingestion_first_dim_reduction.py)
  Loads the raw AVQ data, cleans the working dataset, and produces the reduced feature matrix.

2. [2_feature_selection.py](2_feature_selection.py)
  Performs feature filtering and generates intermediate summaries used in the exploratory phase.

3. [3_exploratory_analysis.py](3_exploratory_analysis.py)
  Produces descriptive plots and bivariate summaries for the target variables.

4. [3_t_SNE_analysis.py](3_t_SNE_analysis.py)
  Explores the structure of the feature space through t-SNE.

5. [4_clustering.py](4_clustering.py)
  Builds respondent clusters and compares them with water-saving and energy-saving outcomes.

6. [5_model_fitting.py](5_model_fitting.py)
  Uses Random Forest and Balanced Random Forest as exploratory models to rank the most relevant variables and summarize the shared correlates of the two targets.

## Main Findings So Far

First of all, the two target variables SPRENER and SPRACQUA are strongly positively associated.
At the same time, several selected features show a coherent gradient across both targets, showing similiar behaviours.
The features that rank highly for both targets include:

- `USAGETT`	-> using disposable products
- `ARUMOR`	-> avoiding noisy driving behaviors
- `ALOCAL` 	-> buying local food/products
- `ETICHET` -> reading food-product labels
- `BIOLOG` 	-> buying organic food/products
- `TRASPO`
- `PUNTIFI10`
- `PUNTIFI3`
- `LIBFAM`
- `ETAMi`

The overall pattern is consistent with a broader sustainability profile: attention to energy and water saving is associated with attention to other sustainable consumption and behavior choices.
The current analysis therefore suggests that water-saving care and energy-saving care are strongly related to a common behavioural profile.
The final conclusion is that attention to saving water and energy does not behave like an isolated outcome. Instead, it appears to be embedded in a broader pattern involving sustainable consumption, everyday habits, and some socio-demographic variables.

## Interpretation Notes

The Random Forest results should be used as exploratory evidence, not as causal proof.

- Feature importance highlights variables associated with the targets.
- It does not show the direction of the relationship.
- It does not establish causality.
- Because the targets are ordinal, a later ordinal model would still be useful for formal interpretation.

Within the scope of this project, the Random Forest stage works best as a final screening tool that helps identify the most plausible correlates to discuss in the study.
